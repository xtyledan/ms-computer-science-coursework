# CS-540 Data Literacy & Visualization

## Module Nine Overview

Module Nine brings together the skills developed throughout **CS-540 Data Literacy & Visualization** in a final project. Students gather data for an organizational decision, create visualizations that reveal key insights, and use those findings to build a data-driven narrative.

The project begins with identifying the decision the data should support and the audience who needs to understand it. Students then select relevant data and create visualizations that make trends, patterns, or gaps clear. The final narrative connects those findings to conclusions that can inform action.

## Real-World Context

Organizations use data to evaluate performance, understand trends, identify problems, and plan improvements. Data professionals must determine which information is relevant, present it accurately, and explain why the findings matter to stakeholders.

A useful visualization does more than display numbers. It helps an audience see an insight that relates to a specific decision. A data-driven narrative provides the context needed to understand that insight and its connection to organizational goals.

## Module Approach

Module Nine consists of a project that applies skills from earlier modules. The work moves from data gathering through visualization to communicating conclusions.

Key steps include:

- Define the decision the analysis will support
- Identify the intended audience and its information needs
- Gather relevant data
- Analyze the data for trends, patterns, and gaps
- Create visualizations suited to the findings
- Develop a narrative that connects the findings to actionable conclusions

## Module Nine Learning Objectives

By the end of Module Nine, students will be able to:

- Gather data required to inform organizational decision-making
- Create data visualizations that reveal key insights
- Use data visualizations to support a data-driven narrative
