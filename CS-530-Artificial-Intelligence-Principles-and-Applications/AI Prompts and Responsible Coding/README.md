<h1 align="center"> AI Code Generation and Intellectual Property</h1>

## Learning Objectives

By the end of this module, the following objectives are demonstrated:

- Demonstrate how to use AI tools to generate code based on given requirements
- Assess the risks associated with intellectual property when using AI-generated code

## Module Overview

Artificial intelligence tools such as **GitHub Copilot** have become valuable resources for software developers by generating code from natural language prompts, completing functions, suggesting algorithms, and assisting with debugging. These tools can significantly improve productivity by reducing repetitive coding tasks and accelerating software development. However, developers must carefully evaluate AI-generated code before incorporating it into projects.

One of the primary concerns surrounding AI-generated code is **intellectual property (IP)**. Questions about code ownership, licensing, copyright, and attribution continue to evolve as AI becomes more widely adopted. Because many AI models are trained on publicly available source code, there is a possibility that generated code may resemble existing copyrighted or open-source software. Developers must understand how software licenses, including open-source licenses such as the **GNU General Public License (GPL)**, can affect the legal use and distribution of AI-generated code.

Another important consideration is transparency. Most AI providers do not fully disclose the datasets used to train their models, making it difficult to determine whether generated code could introduce licensing conflicts or copyright concerns. As a result, software engineers should carefully review AI-generated code for originality, functionality, security, and compliance with project requirements before using it in production environments.

Throughout this module, you will explore how AI tools generate code from software requirements while examining the legal and ethical challenges associated with intellectual property. Understanding these risks allows developers to use AI responsibly, protect software assets, and ensure compliance with licensing and copyright regulations.
