
# CS-600 Software Design and Development

## Course Overview

**CS-600 Software Design and Development** examines how domain storytelling, software development methodologies, and security frameworks contribute to effective software design. Students learn to translate application requirements into understandable workflows, evaluate development approaches, and incorporate security considerations into testing strategies.

The course connects requirements analysis to practical software development decisions. Domain storytelling helps identify stakeholder needs and clarify application workflows, while development methodologies provide structured approaches to project planning and implementation. Security frameworks support the creation of reliable applications by addressing potential vulnerabilities, privacy concerns, and risks throughout development.

## Real-World Context

Successful software development requires clear communication between technical teams, clients, and other stakeholders. Domain storytelling helps teams visualize how users interact with a system, identify missing requirements, and establish a shared understanding of application functionality. This process reduces misunderstandings and supports more informed design decisions.

Selecting an appropriate software development methodology also influences project success. Agile emphasizes flexibility and iterative development, waterfall follows a structured sequence of phases, and DevOps promotes collaboration and continuous delivery. Evaluating these approaches helps teams select processes that align with project requirements, resources, and organizational goals. Integrating security frameworks into application design and test plans further strengthens software reliability by identifying vulnerabilities, protecting sensitive information, and reducing potential risks before deployment.

## Course Approach

This module moves from understanding application requirements through domain storytelling to evaluating software development methodologies and integrating security frameworks into testing strategies.

Key topics include:

- Domain storytelling and application workflows
- Stakeholder communication and requirements analysis
- Identifying gaps, assumptions, and design opportunities
- Agile, waterfall, and DevOps methodologies
- Software development methodology evaluation
- Security frameworks and application protection
- Security testing, privacy, and risk reduction
- Integrating security requirements into test plans

## Learning Objectives

By the end of this module, students will be able to:

- Apply domain storytelling
- Evaluate a software development methodology
- Integrate security frameworks in a test plan
