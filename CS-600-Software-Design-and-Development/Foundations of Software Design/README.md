# CS-600 Software Design and Development

## Course Overview

**CS-600 Software Design and Development** examines how requirements and development approaches shape software projects. Students learn to define what a system must do, identify the standards it must meet, and evaluate whether the finished solution fulfills those expectations.

The course connects software design decisions to measurable outcomes. Performance metrics and key performance indicators (KPIs) help teams assess how well a system meets its requirements and identify areas for improvement.

## Real-World Context

A software solution must do more than provide the requested features. It may also need to meet expectations for usability, security, reliability, performance, scalability, and maintainability. Analysts, architects, and developers use requirements to make these expectations clear before and during development.

Teams also need a development approach that fits the project. Agile, waterfall, spiral, and DevOps provide different ways to organize work, respond to change, and move a solution toward deployment. Selecting an approach requires considering client needs, available resources, technical challenges, and team structure.

## Course Approach

Module One introduces the foundations of software design through requirements analysis, performance measurement, and development paradigm selection.

Key topics include:

- Functional and nonfunctional requirements
- Performance metrics and KPIs
- Usability, security, performance, and scalability
- Reliability and maintainability
- Agile, waterfall, spiral, and DevOps
- Matching a development approach to a problem statement

## Module One Learning Objectives

By the end of Module One, students will be able to:

- Analyze performance metrics and KPIs to determine their relevance to requirements
- Differentiate between functional and nonfunctional requirements for a software solution
- Recommend an appropriate development paradigm for a problem statement
