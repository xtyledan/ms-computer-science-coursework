
# CS-600 Software Design and Development

## Course Overview

**CS-600 Software Design and Development** examines how user interface design, CRUD operations, layered software architectures, and framework-based integration contribute to building functional and maintainable applications. Students learn to identify user actions, design architectural diagrams, and implement user interfaces that connect front-end interactions with application and domain layers.

The course connects software architecture principles with practical UI/UX development. Understanding how user interactions translate into system operations helps developers create applications that are intuitive, efficient, and aligned with user requirements. Frameworks such as Vaadin simplify interface development by allowing developers to integrate user-facing components with back-end functionality.

## Real-World Context

Successful software development requires understanding how users interact with applications and how those interactions affect underlying systems. CRUD operations, including creating, reading, updating, and deleting records, provide the foundation for many application workflows. Identifying these operations helps development teams design interfaces that support user goals while maintaining data integrity and system security. Certain functions may also require access restrictions to prevent unauthorized modifications.

Layered architectures help developers organize applications by separating responsibilities between the presentation, application, domain, and data layers. This separation improves maintainability, flexibility, and scalability by allowing individual components to be modified or replaced without requiring extensive changes throughout the system.

Framework-based UI/UX development further supports efficient software implementation. Frameworks provide reusable components, consistent design patterns, and integration capabilities that reduce development complexity. Using Vaadin allows developers to build interactive Java-based interfaces while connecting directly with back-end services. Testing these integrations helps verify that user actions produce the expected results and that the application functions reliably.

## Course Approach

This module focuses on identifying user interface actions, designing layered software architectures, and implementing and testing framework-based UI/UX integrations.

### Key Topics

- CRUD operations and task-based user interactions
- User interface design and user experience considerations
- Identifying application functionality based on user requirements
- Managing permissions and restricting sensitive operations
- Layered architecture and separation of concerns
- Designing diagrams that represent application layers
- Communication between presentation, application, domain, and data layers
- Framework-based UI/UX development using Vaadin
- Integrating Java-based interfaces with back-end services
- Testing UI functionality and system integration

## Learning Objectives

By the end of this module, students will be able to:

1. Identify CRUD and task-based actions required for a UI.
2. Design a layered architecture diagram.
3. Implement a framework-based UI/UX integration and test.
