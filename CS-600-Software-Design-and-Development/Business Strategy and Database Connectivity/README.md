# CS-600 Software Design and Development

## Course Overview

**CS-600 Software Design and Development** examines how business strategy informs software design. Students use a business model or lean canvas to connect customer needs and value propositions to application requirements, then use a Wardley map to show workflows, dependencies, and how system components evolve.

The course also connects design models to implementation. Configuring database connectivity with Spring JPA demonstrates how an application persists and retrieves data through a database backing store.

## Real-World Context

Software teams need to understand the business problem before deciding which features to build. A canvas gives stakeholders and developers a shared view of customers, problems, and the value a solution should provide. That view helps guide requirements and keep design decisions tied to business priorities.

A Wardley map makes the components and dependencies behind a workflow visible, helping teams discuss where to invest or improve. Database connectivity then supports a working application by giving it reliable access to stored data. This work draws on data access object (DAO) and proxy design patterns.

## Course Approach

This module moves from business strategy to system design and implementation through canvas development, Wardley mapping, and database connectivity with Spring JPA.

Key topics include:

- Business model and lean canvases
- Customer needs, problems, and value propositions
- Stakeholder involvement in requirements
- Wardley maps, workflows, and dependencies
- Component evolution and business priorities
- Spring JPA and database connectivity
- Data persistence, retrieval, and DAO and proxy patterns

## Learning Objectives

By the end of this module, students will be able to:

- Construct a canvas
- Illustrate workflows using a Wardley map
- Implement database connectivity with an appropriate framework
