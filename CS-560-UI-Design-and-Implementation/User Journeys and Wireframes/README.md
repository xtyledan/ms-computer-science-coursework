# CS-560 UI Design and Implementation

## Course Overview

**CS-560 UI Design and Implementation** examines how understanding users shapes interface design. Students use empathy maps and user journeys to explore what people think, feel, and do as they complete a task, then translate those insights into interface workflows.

The course connects user research to practical design decisions. Low-fidelity wireframes show the layout, hierarchy, and intended interactions of an interface, while feedback and iteration help improve its usability.

## Real-World Context

An interface should support the goals of the people using it. Empathy maps help designers recognize user needs and challenges, while user journeys reveal the steps, decisions, and points of friction in a workflow. These tools give teams a clearer basis for deciding what the interface should do.

Low-fidelity wireframes allow teams to explore and communicate ideas before investing in detailed visual design. Reviewing the wireframes and incorporating feedback helps designers find confusing interactions, refine the flow, and better align the solution with user needs.

## Course Approach

This module moves from understanding user behavior to designing and improving an interface through empathy mapping, user journeys, low-fidelity wireframes, and iteration.

Key topics include:

- User thoughts, feelings, motivations, and challenges
- Empathy maps and user journeys
- User goals, decision points, and workflow friction
- Low-fidelity wireframes
- Layout, visual hierarchy, and interaction intent
- Feedback, iteration, and usability improvements

## Learning Objectives

By the end of this module, students will be able to:

- Create empathy maps and user journeys
- Design low-fidelity wireframes that demonstrate layout, hierarchy, and interaction intent
- Refine wireframes through iterative feedback to improve usability and alignment with user needs
